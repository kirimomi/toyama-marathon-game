# 富山マラソンゲーム（仮）

富山マラソンをテーマにしたミニゲーム（PWA）。**現在は会場だけの準備中ページです。**

何を作るかは検討中です。決まり次第、この場所に実装が入ります。

- 外部ライブラリ不使用の素の HTML/CSS/JavaScript 構成
- PWA 対応（ホーム画面に追加／アプリとしてインストール可能、オフラインでも開けます）

## アプリとして置く

- **iPhone**: Safari で開く → 共有 → 「ホーム画面に追加」
- **Windows**: Edge / Chrome で開く → アドレスバーのインストールアイコン（またはメニュー「アプリとしてインストール」）
